# SOC Home Lab

My personal cybersecurity lab, built using **Wazuh, Kali Linux, Docker, and Windows**.

I started this project to get some hands-on experience with security monitoring and understand how a SOC works beyond just watching tutorials.

I'm still learning, so I'll be updating this repository as I make progress, run into problems, and figure things out.

## My setup

- **Kali Linux** running in VirtualBox
- **Wazuh** installed using Docker
- **Windows PC** that I'll use as a monitored endpoint

## What I've done so far

- Set up Kali Linux and configured the network
- Installed Docker and prepared Wazuh
- Generated the required certificates
- Got the Wazuh services running
- Fixed a few installation and connection issues
- Managed to reach the Wazuh Dashboard login page
